## 这是什么

学生时期的实训作品 —— 一个介绍中国传统文化的多页面静态站点。做它的过程基本就是第一次把 HTML / CSS / JavaScript 拼成一个完整的多页网站。

## 页面结构

| 页面 | 内容 |
| --- | --- |
| `index.html` | 首页，各板块入口 |
| `xiqu.html` | 中国戏曲 |
| `yueli.html` | 中式民族乐器 |
| `sougong.html` | 手工艺 |
| `chuancheng.html` | 传承 |
| `show.html` | 展示 |
| `fankui.html` | 反馈 |
| `zhuti1~4.html` | 主题活动页（如「喜迎二十大」主题教育活动） |

## 技术

纯静态：原生 HTML + CSS + JavaScript，无框架、无构建工具，图片资源放在 `assets/` 下，浏览器直接打开即可浏览。

## 说明

这是早期练手项目，代码风格和结构都还比较稚嫩，留作纪念。仓库里另附了一份 `网站.zip` 打包文件。
