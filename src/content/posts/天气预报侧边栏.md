天气预报侧边栏大概是博客里最"有温度"的小组件之一——每次打开首页，右侧栏顺手告诉你所在城市此刻的温度、天气，还有体感、湿度、风力和空气质量。Firefly 本身没有内置这个组件，本文记录从零实现一个完整天气卡片的全过程：数据来自免费的 [UAPI 天气接口](https://uapis.cn/docs/api-reference/get-misc-weather)，无需注册、不用 API Key，默认按访客 IP 自动定位。

## 一、功能概览

![天气预报侧边栏组件](https://muyuimg.cc.cd/file/blog/Jw0d5PTd.webp)

主要能力：

- **三种定位方式** — 不传参数时按访客 IP 自动定位；也可传城市名 `city`（中英文皆可）或行政区划码 `adcode`（优先级最高）
- **基础天气** — 城市/区县、天气图标、当前温度、天气描述、最高/最低温、风力风向、湿度、更新时间
- **扩展气象**（`extended=true`）— 体感温度、能见度、气压、紫外线、云量、降水量、降水概率、空气质量指数与等级、PM2.5/PM10/O₃/NO₂/SO₂/CO 污染物分项、日出日落
- **本地缓存** — 指定城市的结果缓存 30 分钟，减少接口请求；IP 定位不缓存，避免切换网络后显示错位
- **三态 UI** — 加载中 / 加载失败（带重试按钮）/ 数据展示
- **卡片能力** — 基于 `WidgetLayout` 开发，自动继承折叠与入场动画，亮暗色自适应

组件基于 `WidgetLayout` 卡片开发，效果可以直接看本站首页右侧栏。

```astro title="src/components/widget/Weather.astro"
<script is:inline define:vars={{ city, adcode, CACHE_KEY, CACHE_DURATION, extended }}>
	(function () {
		const API_URL = "https://uapis.cn/api/v1/misc/weather?";

		// 缓存管理
		const cacheManager = {
			set: function (key, data) {
				try {
					localStorage.setItem(key, JSON.stringify({
						data,
						timestamp: Date.now()
					}));
				} catch {
					// 忽略存储错误
				}
			}
		};

		// 获取天气数据 - 支持 IP 自动定位
		async function fetchWeather() {
			const params = new URLSearchParams();
			if (adcode) {
				params.set("adcode", adcode);
			} else if (city) {
				params.set("city", city);
			}
			// 如果都没传，不传任何参数，让接口自动根据 IP 定位
			if (extended) {
				params.set("extended", "true");
			}
			// 添加 forecast=true 获取最高/最低温度
			params.set("forecast", "true");

			const url = API_URL + params.toString();
			const response = await fetch(url);

			if (!response.ok) {
				throw new Error(`请求失败: ${response.status}`);
			}

			const data = await response.json();
			
			// 只有指定了城市或adcode时才缓存，IP自动定位不缓存
			// 因为IP可能会变化（切换网络、VPN等）
			if (adcode || city) {
				const cacheKey = adcode ? `adcode_${adcode}` : `city_${city}`;
				cacheManager.set(CACHE_KEY + cacheKey, data);
			}
			
			return data;
		}

		// 天气图标映射
		const weatherIcons = {
			"100": "material-symbols:wb-sunny",
			"101": "material-symbols:cloudy",
			"102": "material-symbols:cloudy",
			"103": "material-symbols:partly-cloudy-day",
			"104": "material-symbols:cloudy",
			"200": "material-symbols:air",
			"201": "material-symbols:water-drop",
			"202": "material-symbols:thunderstorm",
			"203": "material-symbols:rainy",
			"204": "material-symbols:ac-unit",
			"205": "material-symbols:rainy",
			"206": "material-symbols:thunderstorm",
			"207": "material-symbols:snowing",
			"208": "material-symbols:rainy",
			"209": "material-symbols:rainy",
			"210": "material-symbols:thunderstorm"
		};

		function getWeatherIcon(weatherIcon) {
			return weatherIcons[weatherIcon] || "material-symbols:wb-sunny";
		}

		// 更新UI
		function updateUI(container, data, error = null) {
			const loading = container.querySelector("[data-weather-loading]");
			const errorEl = container.querySelector("[data-weather-error]");
			const content = container.querySelector("[data-weather-content]");
			const errorMsg = container.querySelector("[data-error-message]");

			// 隐藏加载状态
			loading.classList.add("weather-hidden");

			if (error) {
				// 如果有错误，显示错误信息，但不隐藏已有的内容
				errorEl.classList.remove("weather-hidden");
				if (errorMsg) errorMsg.textContent = error;
				// 保留服务端渲染的内容（如果有的话）
				return;
			}

			if (!data) {
				// 如果没有数据也没有错误，不做任何操作
				return;
			}

			// 隐藏错误状态
			errorEl.classList.add("weather-hidden");

			// 更新数据
			const setData = (selector, value) => {
				const el = container.querySelector(selector);
				if (el) el.textContent = value || "--";
			};

			setData("[data-city]", data.city);
			setData("[data-district]", data.district);
			setData("[data-temperature]", data.temperature);
			setData("[data-weather]", data.weather);
			setData("[data-wind]", `${data.wind_direction} ${data.wind_power}`);
			setData("[data-humidity]", `${data.humidity}%`);
			setData("[data-report-time]", data.report_time);

			// 更新最高/最低温度
			setData("[data-temp-max]", data.temp_max != null ? String(data.temp_max) : "--");
			setData("[data-temp-min]", data.temp_min != null ? String(data.temp_min) : "--");

			// 更新天气图标
			const iconEl = container.querySelector("[data-weather-icon]");
			if (iconEl) {
				iconEl.setAttribute("name", getWeatherIcon(data.weather_icon));
			}

			// 更新扩展数据
			const extendedSection = container.querySelector("[data-weather-extended]");
			if (extendedSection) {
				// 从 forecast 数组中获取日出日落时间
				const todayForecast = data.forecast && data.forecast.length > 0 ? data.forecast[0] : null;
				
				setData("[data-feels-like]", data.feels_like != null ? `${data.feels_like}°C` : "--°C");
				setData("[data-visibility]", data.visibility != null ? `${data.visibility}km` : "--km");
				setData("[data-pressure]", data.pressure != null ? `${data.pressure}hPa` : "--hPa");
				setData("[data-uv]", data.uv != null ? String(data.uv) : "--");
				setData("[data-precipitation]", data.precipitation != null ? `${data.precipitation}mm` : "--mm");
				setData("[data-cloud]", data.cloud != null ? `${data.cloud}%` : "--%");
				setData("[data-sunrise]", todayForecast?.sunrise || "--:--");
				setData("[data-sunset]", todayForecast?.sunset || "--:--");
				// 降水概率（从 forecast 获取）
				setData("[data-pop]", todayForecast?.pop != null ? `${todayForecast.pop}%` : "--%");
				
				// 空气质量
				const aqiEl = container.querySelector("[data-aqi]");
				const aqiCategoryEl = container.querySelector("[data-aqi-category]");
				if (data.aqi != null) {
					if (aqiEl) aqiEl.textContent = String(data.aqi);
					if (aqiCategoryEl) {
						aqiCategoryEl.textContent = data.aqi_category || "--";
						// 根据空气质量等级添加样式
						aqiCategoryEl.className = "aqi-tag";
						if (data.aqi_level === 1) aqiCategoryEl.classList.add("aqi-good");
						else if (data.aqi_level === 2) aqiCategoryEl.classList.add("aqi-moderate");
						else if (data.aqi_level >= 3) aqiCategoryEl.classList.add("aqi-bad");
					}
				} else {
					if (aqiEl) aqiEl.textContent = "--";
					if (aqiCategoryEl) aqiCategoryEl.textContent = "--";
				}

				// 污染物浓度
				const pollutants = data.air_pollutants || {};
				setData("[data-pm25]", pollutants.pm25 != null ? `${pollutants.pm25}` : "--");
				setData("[data-pm10]", pollutants.pm10 != null ? `${pollutants.pm10}` : "--");
				setData("[data-o3]", pollutants.o3 != null ? `${pollutants.o3}` : "--");
				setData("[data-no2]", pollutants.no2 != null ? `${pollutants.no2}` : "--");
				setData("[data-so2]", pollutants.so2 != null ? `${pollutants.so2}` : "--");
				setData("[data-co]", pollutants.co != null ? `${pollutants.co}` : "--");
			}

			// 显示内容
			content.classList.remove("weather-hidden");
		}

		// 初始化组件
		function initWidget(container) {
			const retryBtn = container.querySelector("[data-retry-btn]");
			const content = container.querySelector("[data-weather-content]");
			const loading = container.querySelector("[data-weather-loading]");
			const errorEl = container.querySelector("[data-weather-error]");

			async function loadWeather() {
				// 显示加载状态，隐藏其他状态
				loading.classList.remove("weather-hidden");
				errorEl.classList.add("weather-hidden");
				content.classList.add("weather-hidden");

				try {
					const data = await fetchWeather();
					updateUI(container, data);
				} catch (e) {
					updateUI(container, null, e.message || "获取天气信息失败");
				}
			}

			// 重试按钮 - 清除缓存后重新加载
			if (retryBtn) {
				retryBtn.addEventListener("click", () => {
					// 清除缓存，强制重新请求
					const cacheKey = adcode ? `adcode_${adcode}` : (city ? `city_${city}` : 'ip_location');
					localStorage.removeItem(CACHE_KEY + cacheKey);
					loadWeather();
				});
			}

			// 自动加载天气数据（基于用户浏览器IP定位）
			loadWeather();
		}

		// 启动
		document.querySelectorAll("[data-weather-init]").forEach(initWidget);
	})();
</script>
```

## 六、城市定位与接口参数

组件请求的是 UAPI 的天气接口：

```text
GET https://uapis.cn/api/v1/misc/weather
```

组件内部按下面的规则拼参数：

```js title="src/components/widget/Weather.astro"
const params = new URLSearchParams();
if (adcode) {
    params.set("adcode", adcode);
} else if (city) {
    params.set("city", city);
}
// 都没传时不带任何定位参数，交给接口按 IP 自动定位
if (extended) {
    params.set("extended", "true");
}
// forecast=true 才会返回最高/最低温、日出日落、降水概率
params.set("forecast", "true");
```

| 参数 | 说明 |
| --- | --- |
| `city` | 城市名，支持中文（`北京`）和英文（`Tokyo`），可选 |
| `adcode` | 行政区划代码（如 `110000`），优先级高于 `city`，可选 |
| `extended` | 返回扩展气象字段（体感温度、能见度、气压、紫外线、空气质量及污染物分项等） |
| `forecast` | 返回多天预报（最多 7 天），并附带当天最高/最低温、日出日落、降水概率 |

### 默认走 IP 自动定位

`city` 和 `adcode` 都不传时，接口会按访客客户端 IP 推导位置并查询天气。组件把这两个 prop 都设为可选，所以默认零配置就能用——访客在哪个城市，就显示哪个城市的天气。

### 想固定城市怎么办

如果希望无论访客在哪都显示你自己所在城市的天气，给组件设一个默认值即可：

```astro title="src/components/widget/Weather.astro" ins={1}
const { class: className, style, city = "青岛", adcode, extended = true } = Astro.props;
```

`adcode` 的优先级最高，想精确到区县时推荐直接填 `adcode`（例如青岛市崂山区为 `370212`）。

## 七、实现要点

### 天气图标映射

接口返回的是数字图标码 `weather_icon`，组件用一张映射表把它翻译成 Material Symbols 图标名：

```js
const weatherIcons = {
    "100": "material-symbols:wb-sunny",
    "101": "material-symbols:cloudy",
    "103": "material-symbols:partly-cloudy-day",
    "104": "material-symbols:cloudy",
    "202": "material-symbols:thunderstorm",
    "203": "material-symbols:rainy",
    "204": "material-symbols:ac-unit",
    "207": "material-symbols:snowing",
    // ...
};
const getWeatherIcon = (code) => weatherIcons[code] || "material-symbols:wb-sunny";
```

命中不到时回退到晴天图标，保证任何天气都有图可显示。

### 缓存策略

指定了城市的结果会写进 `localStorage`，键名带上前缀，有效期 30 分钟：

```js
const CACHE_KEY = "weather_data_cache";
const CACHE_DURATION = 30 * 60 * 1000; // 30 分钟
```

这里有个刻意的设计：**只有传了 `city` / `adcode` 时才缓存，IP 自动定位不缓存**。因为访客可能切换网络或挂代理，IP 会变，缓存下来反而会显示错误城市的天气。点击「重试」按钮时也会先清掉对应缓存再重新请求。

### 扩展信息与日出日落

扩展字段（体感温度、能见度、气压、紫外线、云量、降水量）直接取响应里的同名字段；日出日落和降水概率则来自 `forecast` 数组的第一项：

```js
const todayForecast = data.forecast?.[0] ?? null;
setData("[data-sunrise]", todayForecast?.sunrise || "--:--");
setData("[data-sunset]", todayForecast?.sunset || "--:--");
setData("[data-pop]", todayForecast?.pop != null ? `${todayForecast.pop}%` : "--%");
```

所有取值都做了空值兜底，字段缺失时显示 `--`，不会因为某个城市数据源不全而报错。

### 空气质量配色

AQI 等级 `aqi_level` 为 1~6，组件把它归成三档配色：优/良为绿色、轻度及以上为黄色、再往上为红色，一眼就能看出空气好坏。

### 三态 UI 与错误重试

组件用 `data-*` 属性配合一个 `updateUI()` 统一管理加载、错误、内容三种状态；请求失败时展示错误信息与「重试」按钮，不会白屏。

### 主题适配

温度、标签等文字统一走 `text-neutral-900 dark:text-neutral-100`，图标颜色用主题变量 `--primary`，暗色模式下单独调整了数字颜色与悬浮阴影，保证两种主题下都清晰可读。
