# 2026-10-25

## 新增 /analytics 站点统计页

从 Aemeath 主题（Jarvis0227/Aemeath）移植参考站点 rainzt.cn/analytics 的统计页。

**新增文件**
- `src/pages/analytics.astro`（约 290KB，单文件含模板 + 内联 JS + global style）
- `src/components/widget/AnalyticsSnapshot.astro`（设备/浏览器分布小卡）
- `src/pages/api/github-pushes.json.ts`（构建期读本地 `git log` 生成推送时间，repository 已改为 MuyuDada/Firefly-yuan）
- `public/assets/images/analytics/*.webp`、`public/images/china-blank-province-map.svg`

**修改文件**
- `src/types/analyticsConfig.ts` / `src/config/analyticsConfig.ts`：Umami 增加 `shareApiBase`、`shareId`、`historicalStats`、`hostUrl`、`showPageViews`、`showSiteStats`
- `src/config/navBarConfig.ts`：新增 `LinkPresets.Analytics`（站点统计），挂在「文章」子菜单下

**关键决策**
- 数据源依赖 Umami 的公开分享 API（`/api/share/{shareId}`），需在 Umami Cloud 后台创建 share 后把 ID 填入 `shareId`；未填时页面走「未配置」降级分支，其余模块（推送节奏、最近评论）仍正常。
- 原仓库的中国地图 SVG 来自维基百科，把阿克赛钦/藏南列为独立争议区、缺南海断续线，**不合规**。改用阿里 DataV 省级边界（`100644`→`geo.datav.aliyun.com/areas_v3/bound/100000_full.json` + `100000.json`）重新投影生成，含台湾与九段线，并同步替换页面内联的 `domesticTaiwanPath` / `domesticChinaOutlinePaths` / `domesticRegionCoordinates`。
- 配图由 PNG 转 WebP（5.4MB → 559KB），引用路径同步改为 `.webp`。
- 内部命名空间 `rainzt` → `muyu`，hero 装饰字 `RZ / 2026` → `MUYU / 2026`。

**环境坑**
- `pnpm build` / `astro build` 会因 safe-delete shim 拦截 `node_modules/.vite`、`dist/.prerender/.vite` 的批量删除而失败，需先手动清空这两个目录（要提权）。
- `pnpm build` 后置的 `subset-fonts.ts` 会长时间挂起，验证时直接跑 `npx astro build` 即可。
- 无头截图必须加 `--no-sandbox --disable-dev-shm-usage --user-data-dir=<独立目录>`，否则渲染进程崩溃；页面超过 ~2800px 高度会崩溃，长图要分段截。

**深色模式补丁**
原页面有 17 处 `:root.dark` 覆盖，但地图卡片整块是硬编码浅蓝。已改为 CSS 变量（`--analytics-map-base / -outline / -province / -taiwan-stroke / -taiwan-idle / -fill-1..5`），深色下取深蓝色阶；JS 里 `fillColors` 与台湾默认填充改为 `var(...)`，主题切换时自动跟随。另补了推送状态徽章的深色样式。
