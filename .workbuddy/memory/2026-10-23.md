### 关键决策
- **密钥不进仓库**：高德 Key/安全密钥写 `.env.local`（已 gitignore），页面里 `import.meta.env.PUBLIC_*` 优先、
  `siteConfig.placesMap` 兜底。部署平台（Vercel/Cloudflare）要另配同名环境变量。
  这是静态站，Key 必然内联进 HTML，防护只能靠高德控制台的**域名白名单**。
- **Swup 兼容**：数据走 `<script type="application/json" id="places-client-payload">` + 内联脚本，
  用 `window.__placesPage` 守卫；二次进入只 `refresh()`（destroy → init），离开页面监听 `swup:contentReplaced`
  判断 `.places-page` 消失则销毁地图（防 WebGL 上下文泄漏）。不用 define:vars（Swup 重入会丢）。
- **map 实例顺序坑**：`createMap()` 里先 `destroyMap()` 会把 `state.AMap` 清空，必须在销毁后重新赋值，
  否则 `renderMarkers` 提前 return、地图空白。

## 修「点气泡没反应」

现象：地图上点 marker 不出弹窗。原实现走 `marker.on("click")` + `AMap.InfoWindow`，
两层都不可靠：MarkerCluster 会接管 marker、自定义 content 的 click 常被吞；InfoWindow 的
`isCustom` 容器还有自己的定位/样式坑。

改法（不依赖 AMap 事件系统）：
- 地图容器 `.places-map-wrap` 上挂 **capture 阶段** 的 click 委托，用 `target.closest('.places-pin')`
  取 `data-place-id` → `openPopup`；cluster 气泡带 `data-cluster-id`，簇内 members 存在
  `state.clusterMembers`，点击照样能放大拆分；点空白处关弹窗。
- 弹窗改成**自绘层**：`.places-map-wrap > .places-popup-layer`（pointer-events:none），
  弹窗本体 absolute + `map.lngLatToContainer()` 定位，上方放不下自动翻到下方，左右夹在容器内；
  监听 `mapmove / zoomchange / moveend` 实时跟随。InfoWindow 相关代码全部删掉。
- 顺带：点地点卡片现在直接飞到点并打开弹窗；重新锁定时自动收起弹窗。

## 标点不显示的真正原因（重要结论，别再踩）

用户反馈「地图上看不到标点」。用 Chrome headless（`--no-proxy-server`，走直连才行）实测定位：

**`AMap.MarkerCluster`（JS API 2.0）只接受「数据点数组」，不接受 `AMap.Marker` 实例。**
传 Marker 数组进去：**不报错、不抛异常、但一个点都不渲染**。对照实验：
- `map.add(marker)` → 渲染 ✓
- `new AMap.MarkerCluster(map, [marker], opts)` → 0 个 ✗（静默失效）
- `new AMap.MarkerCluster(map, [{lnglat:[lng,lat]}], {renderMarker})` → 渲染 ✓

而且数据点模式下，插件会把数据包成自己的结构（带 `originData` 循环引用），**自定义字段不透传**，
`renderMarker` 里拿 `ctx.data.place` 是拿不到的；不处理就用默认蓝色图标 `mark_bs.png` 覆盖你的 content。

**最终方案：彻底不用 MarkerCluster**，自己管：
- 每个点位一个 `new AMap.Marker({position, content: pinHtml(place)})` + `marker.setMap(map)`
- 聚合自己算：`map.lngLatToContainer()` 把点转像素 → 按 72px 网格分桶 → 同桶 >1 就 `marker.hide()`
  并在平均坐标放一个 `AMap.Marker`（圆气泡，带 `data-cluster-id`）；点气泡 `zoom +2` 拆开
- 监听 `zoomend` / `moveend` 重算；`fitView` 改成用 `new AMap.Bounds(sw, ne)` + `map.setBounds(...)`（`setFitView` 需要 overlay 数组）
- 补了 footprintmap 那个「集群显示」开关（`aria-pressed` + 滑块 CSS），关掉时全部按单点铺开

### 环境坑补充
- 无头 Chrome **默认走系统代理**，拿不到 `webapi.amap.com`；必须加 `--no-proxy-server` 才能拉到高德脚本。

## 修「杭州不亮」+ 控件开关

### 杭州不亮的真因：浙江有 563 个边界环
实测 `DistrictSearch`（search 浙江省, extensions:'all'）返回 **`boundaries.length = 563`**（舟山群岛一堆小岛），
而陕西只有 3。原来一个环建一个 `AMap.Polygon`，浙江瞬间建 563 个覆盖物 → 卡住/几乎看不见。

修法：每个省只画**点数最多的前 10 个环**（主陆地 + 主要岛屿），跳过 <12 点的碎片环，单个环 try/catch。
另外 `fillOpacity` 0.15 → 0.28：陕西那种多环嵌套会因为叠加而显得更实，浙江是独立岛屿单层，0.15 太淡。

验证：`map.getAllOverlays('polygon')` 从卡顿变成稳定 22 个（4 个省）。

### 控件开关的视觉 bug

只有底部那个「集群显示」开关会变色；设置面板里的「地图控件」虽然行为正确，但滑块不动。
改成 `[aria-pressed="true"] .places-cluster-switch`，两个开关共用。
