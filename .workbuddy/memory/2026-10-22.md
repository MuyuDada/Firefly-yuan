## 环境坑：git push 需绕过沙箱代理

- 直接 `git push` 报 `schannel: failed to receive handshake, SSL/TLS connection failed` / `Empty reply from server`，原因是继承了环境变量 `http_proxy/https_proxy=http://127.0.0.1:21751`（WorkBuddy 沙箱代理）。
- 可用解法：`env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY git push origin master`（直连即可，无需 sslBackend 也可）。
